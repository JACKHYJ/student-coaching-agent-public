# Student Coaching Agent

面向国际教育场景的学生支持与学习辅导工作流。

本仓库是公开分享的纯净版：不包含真实学生资料、真实学号、成绩、会议记录、原始报告或个人配置。请使用虚构案例或经过充分脱敏的数据。

## 内容

- `student-records/`：空白学生档案模板
- `automation-input/`：学业风险巡检规则与输入格式
- `中文蒸馏版/`：辅导与行为改变相关的知识材料
- `examples/`：风险巡检示例脚本

## 使用边界

- 缺失数据标记为“未知”，禁止推测。
- 风险提示不能替代专业判断或正式管理决定。
- 不进行人格、动机或心理诊断。
- 使用真实资料时，应遵守适用的隐私、数据保护和机构政策。

## 快速开始

1. 复制 `student-records/Student_Record_Template.md`，为本地学生建立档案。
2. 使用仅含脱敏代码的 CSV，参照 `automation-input/risk-rules.md` 运行巡检。
3. 不要将本地真实资料提交到 Git；仓库已通过 `.gitignore` 忽略本地数据目录。
